# AbelFitness

Página de presentación interactiva para entrenador personal (AbelFitness).

## 🚀 Características
- **Aesthetica Deportiva Premium**: Tema oscuro moderno con acentos verde voltio/neón y fuentes elegantes.
- **Opiniones estilo WhatsApp**: Un carrusel dinámico y arrastrable que emula burbujas de conversación reales de WhatsApp.
- **Precios Dinámicos**: Tarifario con selector de facturación Mensual/Trimestral que recalcula los precios automáticamente.
- **Integración con WhatsApp**: Los botones de compra generan enlaces wa.me con mensajes dinámicos precompletados según el plan y periodo elegido.
- **Scroll Entrance Reveals**: Elementos que aparecen y se animan al hacer scroll en pantalla, optimizado para móvil y ordenador.

## 📁 Estructura del Proyecto
* `index.html` - Estructura semántica de las secciones.
* `styles.css` - Estilos con variables CSS, animaciones y responsive design.
* `script.js` - Control del carrusel, toggles y lógica de contacto.
* `img/abel_trainer.jpg` - Recurso de imagen fotorrealista para el perfil.
